# v1.0.1：窗口销毁报错修复

修复关闭、退出或重建窗口后，迟到的 IPC 消息访问旧 `BrowserWindow` / `webContents`，导致 `TypeError: Object has been destroyed` 的错误。统一入口先检查退出状态、窗口和内容对象是否销毁，再检查消息来自当前主框架；销毁期间的消息直接忽略。正常窗口中的保存、交互、聚焦与就绪处理保留。

本次功能代码只修改 `desktop/main.cjs`。公开源码沿用 v1.0.0 的现有默认图标映射；完整 Windows 安装器沿用当前本机 membership.5 的文件和安装流程，除主进程修复外其余 225 个载荷文件字节不变。没有升级运行组件或调整角色、人设、提示词、API、余额、聊天、气泡与跟随功能。

Windows 安装包：`CodexWhale-v1.0.1-Setup-x64.exe`；内部安装目录标识为 `0.2.4+membership.6`。打开安装包，点击“安装并启用”，然后打开 Codex。需要 Windows 10/11 x64 和 Codex 桌面应用。朋友使用自己的 API Key；安装包不包含制作者个人 Key、账户登录态、配置、账本或聊天数据。

回归覆盖当前主框架正常 IPC、退出中、窗口销毁、内容对象销毁、窗口缺失、框架销毁以及外部发送者/子框架，共 7 项。另在实际 EXE 的隔离安装目录中核对全部 226 个载荷文件和专用计划任务，并用其内置 Electron 创建和销毁真实窗口，向六类 IPC 投递迟到消息。具体结果和 EXE SHA-256 见 Release 校验附件；这不是全部功能已重新手工测试或不存在其他缺陷的保证。

完整包内的许可和第三方源码材料保持原样，适用范围仍由各许可文件分别确定；本次没有扩大素材授权声明。构建与解压说明见 `installer/README.md`。
